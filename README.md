# controlechoco

Controle de custos, estoque, encomendas e preço de venda da Confeitaria Choco, em uma página só (`index.html`).

## Publicar no GitHub Pages

1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.
3. Salve. Em um ou dois minutos o site fica em `https://opradopedro.github.io/controlechoco/`.

## Onde ficam os dados

Tudo é salvo no navegador de quem usa (localStorage). Nada vai para servidor nenhum.
Cada celular ou computador tem os próprios dados. Para levar de um aparelho para outro,
use **Ajustes → Baixar backup** e depois **Restaurar backup** no outro aparelho.
